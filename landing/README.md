# Лендинг «Сборные грузы из Европы и Китая в Москву»

Одностраничный сайт с формой заявки. Это статический HTML/CSS/JS и один PHP-обработчик, без сборки и без внешних сервисов: шрифты и картинки лежат локально.

## Дизайн и технологии

- Тёмная тема, шрифты Unbounded, Manrope и JetBrains Mono. Все шрифты лежат локально.
- Первый экран: видео на фоне, сетка и свечение, интерактивный виджет сроков доставки по маршрутам (управляется клавиатурой).
- Анимированная SVG-карта маршрутов: Римини, Вильнюс и Гуанчжоу → Москва.
- Bento-сетка услуг с подсветкой за курсором. Бегущая строка, плавное появление блоков при прокрутке.
- Индикатор прокрутки, линия прогресса в «шагах», липкая кнопка заявки на телефоне.
- Анимации отключаются, если в системе включено «уменьшить движение». Видео не грузится в режиме экономии трафика.
- Без фреймворков и сборки: страница лёгкая и быстро открывается.

## Состав

| Файл | Назначение |

| `index.html` | Лендинг: первый экран, маршруты и сроки, услуги, что возим, сравнение, шаги, форма, FAQ |
| `privacy.html` | Политика обработки персональных данных (ст. 18.1 152-ФЗ) и раздел о cookie |

| `thanks.html`, `404.html` | Страница «спасибо» (работает без JS) и страница ошибки |

| `.htaccess` | Закрывает служебные файлы, включает кэш и заголовки безопасности (Apache) |

## Запуск

1. Нужен хостинг с PHP 8 и HTTPS, серверы в РФ (например, Timeweb, Beget, REG.RU).
2. Загрузите содержимое папки `landing/` в корень сайта.
3. Скопируйте `config.example.php` в `config.php` и укажите почту для заявок. Telegram необязателен (см. юридический раздел).
4. Проверьте, что папка `storage/` недоступна из браузера: `https://ваш-сайт/storage/leads.csv` должен отдавать 403.
   - На nginx добавьте в конфиг `location ^~ /storage/ { deny all; }`.
   - Ещё лучше указать в `config.php` папку вне корня сайта.
5. Замените `https://example.ru` на ваш домен во всех файлах: `index.html`, `privacy.html`, `consent.html`, `robots.txt`, `sitemap.xml`.
6. Яндекс Метрика: впишите номер счётчика в `assets/app.js` (`METRIKA_ID`). Счётчик загружается только после согласия посетителя в уведомлении о cookie.

Локальная проверка: `cd landing && php -S 127.0.0.1:8080`, затем открыть http://127.0.0.1:8080.

## Что заполнить перед публикацией

Все места для заполнения помечены квадратными скобками `[...]`, а в документах ещё и выделены жёлтым:

- наименование организации или ИП, ИНН, ОГРН, юридический адрес;
- телефон, e-mail, адрес склада в Москве;
- e-mail для обращений по персональным данным;
- номер в реестре операторов ПДн Роскомнадзора;
- данные хостинг-провайдера (наименование, ИНН, адрес).

## Юридический чек-лист (РФ)

- [x] Политика обработки ПДн опубликована. Ссылки на неё есть в подвале и у формы.
- [x] Согласие оформлено отдельным документом, чекбокс по умолчанию не отмечен. Без согласия форма не отправляется.
- [x] В журнале заявок сохраняются дата, IP и версия текста согласия. Это подтверждает, что согласие было получено.
- [x] Форма собирает только необходимые данные (минимизация).
- [x] Cookie-уведомление есть. Аналитика подключается только после «Принять».
- [x] Оговорка «не является публичной офертой». Сроки и цены указаны как ориентир.
- [ ] **Подать уведомление в Роскомнадзор** об обработке ПДн (pd.rkn.gov.ru), если оператор ещё не в реестре.
- [ ] **Локализация.** Сайт и журнал заявок должны храниться на сервере в России.
- [ ] **Telegram и зарубежная почта** (Gmail и т. п.) — это трансграничная передача ПДн. До включения подайте уведомление в РКН и допишите раздел 5.4 политики. Проще получать заявки на почту российского сервиса.
- [ ] Назначить ответственного за обработку ПДн и утвердить внутренние документы (приказ, положение).
- [ ] При запуске рекламы маркировать рекламные материалы (ERID) — это требование к рекламе, не к сайту.

Тексты политики и согласия — шаблон по 152-ФЗ. Перед публикацией их стоит показать юристу.

## Контент

На сайте использованы только факты из брифа:
- склады в Римини и Вильнюсе;
- сроки 18–25, 14–21, 25–30 и 35–45 дней, авиадоставка;
- белая растаможка, оплата инвойсов, упаковка, страхование;
- «Честный знак», проверка по санкционным кодам;
- персональный менеджер, еженедельные отправки, любой объём.

Цен и сравнений с конкурентами нет. Фото — кадры из бесплатных роликов Pexels (лицензия Pexels допускает коммерческое использование).
