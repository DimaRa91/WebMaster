# Промо-ролик «Сборные грузы из Европы и Китая в Москву»

Вертикальный ролик **1080×1920 (9:16), 30 fps, 50 секунд**, H.264 + AAC 48 кГц. Один файл подходит для
Instagram Reels, TikTok и YouTube Shorts: формат 9:16, длительность меньше 60 с, текст в общей безопасной зоне всех трёх площадок.
Названия и логотипа компании в ролике нет.

- **Готовое видео:** [`out/promo.mp4`](out/promo.mp4)
- **Исходники:** Remotion 4 (React + TypeScript), папка [`src/`](src); таймлайн в [`src/Promo.tsx`](src/Promo.tsx)
- **Саундтрек:** [`public/soundtrack.wav`](public/soundtrack.wav), генерируется скриптом [`music/compose.py`](music/compose.py)

## Сценарий и монтаж

Темп трека 120 BPM: доля = 0,5 с = 15 кадров. Все склейки и удары стоят на этой сетке.

| Время | Блок | Что на экране |
|---|---|---|
| 0–3 с | Хук | «ВЕЗЁТЕ / ТОВАР / ИЗ ЕВРОПЫ / И КИТАЯ?», удар на каждую долю; падает 3D-коробка |
| 3–9 с | Санкции | штамп «САНКЦИИ», путь закрыт, 4 боли: оплата инвойса, маленький объём, серая таможня, хаос в документах; «бизнес на паузе?» |
| 9–12 с | Поворот | «НО ЕСТЬ ДРУГОЙ МАРШРУТ», крен и нырок камеры, пауза в музыке |
| 12–14 с | Дроп | «ИЗ ИТАЛИИ, ЕВРОПЫ И КИТАЯ → В МОСКВУ», «для вашего бизнеса» |
| 14–18 с | Европа | склад в Римини (Сассуоло, Пезаро, Марке), отъезд камеры к складу в Вильнюсе; сроки 18–25 и 14–21 день |
| 18–22 с | Китай | Гуанчжоу → Москва: ЖД 35–45 дней, авто 25–30 дней, авиа организуем |
| 22–24 с | Консолидация | «от одной коробки», обрешётка, «застраховано» |
| 24–26 с | Что везём | категории товаров меняются в ритм мелодии |
| 26–32 с | 6 решений | оплатим инвойс · белая растаможка · полный пакет документов · проверим товар, включая санкционные коды · марки «Честный знак» · многолетний опыт |
| 32–36 с | Менеджер | переписка с персональным менеджером |
| 36–38 с | Еженедельно | «отправки каждую неделю» |
| 38–43 с | Итог | чек-лист «всё под ключ» из 8 пунктов |
| 43–45 с | Нарастание | «сколько стоит ваша доставка?» |
| 45–50 с | Финал | «СБОРНЫЕ ГРУЗЫ», кнопка «РАССЧИТАТЬ СТОИМОСТЬ ДОСТАВКИ», «Пришлите инвойс или список товаров» |

## Безопасные зоны Reels / TikTok / Shorts

Значимый текст стоит в зоне `x 80–960, y 260–1440`; правее `x 960` ниже `y 800` текста нет (колонка
лайков). Это пересечение зон всех трёх площадок, самая строгая из них TikTok. Зоны заданы в
`src/theme.ts` (`SAFE`). Превью с наложенной сеткой:

```bash
npx remotion render src/index.ts Promo out/preview_safe.mp4 --props='{"safeZones":true}' --scale=0.5 \
  --browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell
```

## Факты в ролике (из брифа клиента)

- Сборные грузы из Италии, Европы и Китая в Москву.
- Склад консолидации в Римини (рядом Пезаро — мебель, Сассуоло — керамика, Марке — обувь), забор с фабрик. Второй склад в Вильнюсе (Германия, Польша, другие страны ЕС). Сроки: Римини 18–25 дней, Вильнюс 14–21 день.
- Китай, Гуанчжоу: ЖД 35–45 дней, авто 25–30 дней, авиадоставка по организации (срок не указан).
- Любой объём от одной коробки, упаковка, обрешётка, страхование.
- Оплата инвойса поставщику, белая растаможка, полный спектр таможенного оформления и пакет документов.
- Проверка товара, включая санкционные коды. Заказ марок «Честный знак».
- Еженедельные отправки, многолетний опыт, персональный менеджер.
- Стоимость считается индивидуально по инвойсу или списку товаров, до склада в Москве.

Цен, конкретного числа лет опыта и дня недели отправки в ролике нет. Переписка с менеджером — иллюстрация.

## Музыка и звук: источники

| Что | Источник | Лицензия |
|---|---|---|
| Весь трек (бит, 808-бас, суперсо-аккорды, мелодия) | **оригинальная композиция**, синтезирована с нуля кодом [`music/compose.py`](music/compose.py) (numpy/scipy), без сэмплов и чужих записей | принадлежит владельцу проекта, проблем с авторскими правами нет |
| Звуковые эффекты (удары, свуши, нарастания, реверс-тарелка, клик кнопки, сирена) | синтезированы тем же скриптом | то же |

Почему не Mixkit: сетевая политика среды, в которой собирался ролик, блокировала `mixkit.co`
(и другие стоковые хосты). Синтез решил это, и заодно трек написан точно под монтаж:
каждый удар стоит на нужном кадре.

**Как заменить на трек Mixkit:** скачайте любой трек с <https://mixkit.co/free-stock-music/>
(Mixkit License: бесплатно, в том числе для коммерческого использования, без указания автора),
лучше около 120 BPM и не короче 50 с, затем положите его в `public/soundtrack.wav` (или поменяйте путь в
`src/Promo.tsx`) и выровняйте дроп трека на 12-ю секунду. Пересобрать оригинальный трек:
`pip install numpy scipy && python3 music/compose.py`.

## Шрифты и графика

- **Unbounded** (заголовки), **Inter** (текст), **JetBrains Mono** (служебные подписи). Все под SIL Open Font License 1.1, подключены локально через пакеты Fontsource (`public/fonts`).
- Коробка, фуры, самолёт, иконки, карты и чат нарисованы в коде (CSS/SVG). Чужих картинок нет.
- Палитра ролика: тёмный `#0B0C12`, кремовый `#F3EEE2`, сигнальный оранжевый `#FF4D12`, кобальт `#2236FF`, красный «санкций» `#E5000F`.
